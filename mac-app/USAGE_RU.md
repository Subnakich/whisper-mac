# Whisper Mac: установка и работа

## Установка

Собранный установщик:

```text
/Users/subnak/dev/whisper-gui/mac-app/build-fixed/WhisperMac-0.2.0.pkg
```

Откройте `.pkg` двойным кликом и установите приложение. Оно появится здесь:

```text
/Applications/Whisper Mac.app
```

Текущий локальный пакет не подписан сертификатом Apple Developer ID. Если macOS заблокирует запуск, откройте «Системные настройки → Конфиденциальность и безопасность» и подтвердите открытие. Для публичного распространения пакет нужно подписать и нотариализовать.

## Первый запуск

1. Откройте `Whisper Mac`.
2. Нажмите «Подготовить приложение».
3. Дождитесь сообщения «Всё готово».
4. Выберите профиль модели.
5. Если нужна диаризация, сохраните Hugging Face token в Keychain.
6. Можно сразу начать обработку — недостающие файлы загрузятся автоматически. Для предварительной загрузки откройте меню `•••` и выберите «Скачать выбранный режим для офлайн-работы».

Runtime и модели находятся вне `.app`:

```text
~/Library/Application Support/WhisperMac/runtime
~/Library/Application Support/WhisperMac/models
```

Обновление приложения не удаляет эти каталоги.

## Модели

### Быстрее

```text
mlx-community/whisper-large-v3-turbo
```

Рекомендуемый профиль: Metal-ускорение, около 1.6 ГБ модели, хороший баланс скорости и качества.

### Точнее

```text
mlx-community/whisper-large-v3-mlx
```

Полный `large-v3`, около 3.1 ГБ. Требует больше объединённой памяти и работает медленнее.

### Своя модель

Можно указать Hugging Face model ID или путь к локальной MLX Whisper-модели.

## Диаризация

Используется:

```text
pyannote/speaker-diarization-community-1
```

Перед первой загрузкой:

1. Примите условия на [странице модели](https://huggingface.co/pyannote/speaker-diarization-community-1).
2. Создайте Hugging Face read-token.
3. Вставьте token в поле «Ключ доступа».
4. Нажмите «Сохранить».

Если приложение сообщает, что не удалось обработать запись, убедитесь, что условия модели приняты в том же аккаунте Hugging Face, для которого создан token. В приложении появится кнопка «Открыть доступ», ведущая на нужную страницу.

Token хранится в macOS Keychain и не записывается в настройки приложения или результаты.

Если точное число участников известно, выберите его в списке — доступны значения от 2 до 20. В остальных случаях оставьте «Определить автоматически».

### Запоминание голосов

После готовой расшифровки приложение покажет найденных участников. Введите имя рядом с неизвестным голосом и нажмите «Запомнить». В следующих записях имя будет подставлено в TXT, Markdown, JSON и субтитры, если совпадение достаточно уверенное.

Сохранёнными именами можно управлять в блоке «Знакомые голоса». Исходные аудиофрагменты не копируются: локально остаётся только компактный числовой профиль голоса. Профили находятся в `~/Library/Application Support/WhisperMac/speaker-profiles.json` и никуда не отправляются.

## Настройки распознавания

- «Язык»: для русских записей рекомендуется «Русский», а не «Авто».
- «Подсказка»: имена, названия компаний, продукты и специальные термины.
- «Определять спикеров»: отключите для одного говорящего или более быстрой обработки.
- «Быстрое разделение голосов»: использует ускорение Apple Silicon и включено по умолчанию. Если операция не поддерживается, приложение автоматически продолжит в совместимом режиме.
- «Текст»: читаемая расшифровка TXT.
- «Markdown»: оформленный документ MD с репликами и временем.
- JSON: реплики и таймстампы каждого слова.
- SRT/VTT: субтитры.

## Обработка записи

1. Нажмите «Выбрать запись…».
2. Выберите аудио или видео.
3. Нажмите «Каталог результатов…».
4. Проверьте модель, язык, диаризацию и форматы.
5. Нажмите «Создать расшифровку».
6. После завершения при желании дайте найденным голосам имена для будущих записей.

Во время работы приложение показывает текущий этап, прошедшее время и прогресс. Для распознавания также отображаются процент и скорость относительно длительности записи, например `8,4× реального времени`. При первой загрузке модели видны скачанный и полный объём. Процесс можно остановить; уже загруженные данные останутся в кэше. Исходный файл не изменяется.

## Управление кэшем

- «Открыть кэш» показывает каталог моделей в Finder.
- «Очистить модели» удаляет только модели и связанные кэши.
- Runtime остаётся установленным.
- Удалённые модели автоматически загрузятся при следующем запуске.

## Размер установки

Сам `.pkg` занимает меньше 1 МБ, потому что содержит только нативное приложение и код пайплайна. После первого запуска дополнительно загружаются:

- управляемый Python и ML runtime;
- MLX, PyTorch и pyannote — ориентировочно 1–2 ГБ;
- ASR-модель — примерно 1.6 или 3.1 ГБ;
- модель и компоненты pyannote.

Такой подход сохраняет установщик лёгким и позволяет загружать только действительно выбранные модели.
